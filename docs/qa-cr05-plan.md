## 一、测试环境与约定

1. 一律临时目录数据库 + 随机端口，**不碰 `instance/payment_progress.db`**；用例结束清理。
2. 需要改库的断言（如令牌置过期、金额制造超付）只在临时库上直接 `UPDATE`。
3. 表单 `name` 与设计 §4.1/§6.1/§7.2 一致：`shot_amount/shot_payment/shot_warranty`、`ratio_*`、`apply_no`、`paid_amount/pay_date/pay_method/voucher_no`、`confirm_token`。
4. OCR 依赖本机 WinRT：不把 OCR 文本作为唯一验收标准；OCR 不可用时应走「降级手填」路径仍可完成业务（见 ① 组）。
5. 判定：每需求给出「通过 / 不通过 + 复现步骤」；不通过项不得用 xfail 掩盖（只有真实缺陷才标 xfail 并报 Chief）。
